# Brazilian Core

## Casa de perfumaria brasilieira

### Requisitos
- docker intalado (https://www.docker.com/get-started/)

### Como rodar
``` bash
docker compose up --build
```

- Crie um **.env** de acordo com o **.env.example** e adicione suas credencias de conexão com o banco de dados

#### **Documentação da API**
http://localhost:8000/docs

#### **Frontend**
http://localhost:3000

- No arquivo documentacao.pdf tem todos os comandos sql utilizados no projeto
